# ssp-mirror
ssp-mirror - промежуточный узел в системе SSP (Secured SeamlessTCP Proxy).
Роль этого сервиса состоит в создании альтернативных маршрутов до сервера системы, 
а также предотвращения раскрытия целевого IP-адреса сервера при соединении.

## Конфигурация
`host` - адрес для привязки

`target` - целевой адрес назначения

`timeout` - максимальное время ожидания ответа при передаче данных

`log_level` - уровень логирования
